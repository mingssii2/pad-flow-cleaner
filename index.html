How it works 
Clean (Mode B): pre-flatten multi-line $'''...''' (DOTALL)
               drop line containing '"Repository": "{' entirely
               drop default params: WaitForPageToLoadTimeout, UseMachineLocale,
                 ClearCache, ClearCookies, Timeout, PiPUserDataFolderMode,
                 TargetDesktop, UnfocusAfterPopulate
               collapse appmask['...']['name'] to [name]
               shorten WebAutomation.X.Y -> Web.Y
               normalize whitespace (4-space indent -> 2-space)
               SCRUB sensitive data:
                 - PAD encrypted: Text: P'...' -> <REDACTED_ENCRYPTED>
                 - selector-context field values for password/secret/token/
                   apikey/username/email/login (handles \' escape) -> <REDACTED>
                 - JWT, Bearer, AWS (AKIA*), GitHub PAT (ghp_*), Slack (xox*)
                 - URL embedded creds: https://u:p@h -> https://<REDACTED>@h
                 - Connection-string Password=X / Pwd=X
                 - TH National ID / phone (with label)
                 - Plain emails -> <REDACTED_EMAIL>

Graph (Mode C, runs on Mode B output): drop ControlRepository tail
               stack-based parser tracks LOOP/IF/BLOCK frames
               IF branches: yes/no labels, merge at END
               LOOP: back-edge from body tail to head (dashed "iter")
               LOOP exit: edge from head to post-END node (labeled "done")
               GOTO X / NEXT LOOP: dashed back-edge to LABEL X or loop head
               label shortener compresses each line to verb + key arg
               emits Mermaid flowchart TD; shapes vary by node kind
